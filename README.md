# صيّاد الخليج — Gulf Fisher (MVP)

تطبيق ويب تقدّمي (PWA) عربي لصيادي الإمارات: خريطة، طقس بحري، نافذة طلعة، مد وقمر، بقع مرجّحة (تقدير)، نقاط سرّية مشفّرة على الجهاز، سجل صيد، تعرّف على السمك بالذكاء الاصطناعي، الأنظمة، والسلامة.

- الدخول مقصور على حساب المالك (Supabase Auth، التسجيل مقفل).
- البيانات محمية بـ RLS، والنقاط مشفّرة AES-GCM بعبارة مرور لا تغادر الجهاز.
- مفاتيح الذكاء الاصطناعي في Edge Function فقط؛ المستودع لا يحتوي أسراراً (المفتاح anon عام بطبيعته).

⚠️ ليس للملاحة. البقع تقدير حسابي وليست ضماناً.

Data: Open-Meteo (CC BY 4.0), GEBCO, OpenStreetMap contributors, MOCCAE/EAD sources linked in-app.
